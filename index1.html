Things I've built.

Turning ideas into practical solutions through technology.

01

Smart Classroom Noise Alert System

The Smart Classroom Noise Alert System is an innovative project that aims to improve the learning environment by monitoring classroom noise levels in real time. The system provides alerts when the noise exceeds a predefined threshold, helping students and teachers maintain a focused and productive atmosphere.

This project demonstrates the practical application of IoT, sensors, and automation to solve a real-world problem. It is a useful and promising solution that can be further enhanced with AI-based noise classification, data analytics, and a web dashboard for monitoring classroom conditions.
